# 中文学术论文格式化规范参考

本文档详细说明技能使用的排版规则、标题检测算法和脚注处理方式。

## 1. 排版规则速查

### 论文题目
- **字体**: 黑体 (SimHei)
- **字号**: 四号 (14pt)
- **加粗**: 否
- **对齐**: 居中
- **行距**: 单倍行距
- **检测**: 文档第一个非空段落

### 一级标题 (格式 "一、")
- **字体**: 宋体 (SimSun)
- **字号**: 小四 (12pt)
- **加粗**: 是
- **对齐**: 居中
- **行距**: 单倍行距
- **检测**: 匹配正则 `^[一二三四五六七八九十百千]+[、．.]`，段落长度 ≤ 40 字符

### 二级标题 (格式 "（一）")
- **字体**: 楷体 (KaiTi)
- **字号**: 小四 (12pt)
- **加粗**: 是
- **对齐**: 左对齐
- **行距**: 单倍行距
- **缩进**: 首行缩进 2 字符
- **检测**: 匹配正则 `^（[一二三四五六七八九十百千]+）`，段落长度 ≤ 50 字符

### 三级标题 (格式 "1. ")
- **字体**: 宋体 (SimSun)
- **字号**: 五号 (10.5pt)
- **加粗**: 是
- **对齐**: 左对齐
- **行距**: 单倍行距
- **缩进**: 首行缩进 2 字符
- **检测**: 匹配 `^\d{1,3}[\.、．]\s` (带空格) 或 `^\d{1,3}[\.、．]\S` (不带空格时仅 ≤15 字符)

### 正文
- **中文字体**: 宋体 (SimSun)
- **西文字体**: Times New Roman
- **字号**: 五号 (10.5pt)
- **行距**: 单倍行距
- **缩进**: 默认不缩进，可通过 `--body-indent 2` 设置首行缩进2字符

### 脚注
- **字体**: 宋体 (SimSun)
- **字号**: 小五号 (9pt = 18 half-pts)
- **行距**: 单倍行距
- **编号**: 数字 (1, 2, 3…)，每页重新编号
- **处理**: 仅格式化 .docx 已有的 Word 脚注。手动输入的注释文本不会被检测为脚注

## 2. 标题检测算法

### 检测流程

```
段落文本 → 去除首尾空白
  → 三级检测 (最易误判, 先检测)
    → ^\d+[\.、．]\s + 长度 ≤ 60 → 三级标题
    → ^\d+[\.、．]\S + 长度 ≤ 15 → 三级标题 (紧密格式)
  → 二级检测
    → ^（[一二三…百千]+） + 长度 ≤ 50 → 二级标题
  → 一级检测
    → ^[一二三…百千]+[、．.] + 长度 ≤ 40 + 前面没有"第""其"等字 → 一级标题
  → 都不匹配 → 正文
```

### 误判保护

- **一级标题**: 排除 "第一，"、"其一、" 等前置词干扰
- **三级标题**: 区分 "1. 标题" (三级标题) 和 "1.2 数据" / "2023年..." (不是标题)
- **长度限制**: 超过阈值的长段落不会被判定为标题
- **空行**: 题目区域检测在遇到空行或标题时结束

## 3. 脚注处理技术

### python-docx 脚注操作

python-docx 没有公开的脚注 API，本技能通过 lxml 直接操作 XML:

1. 通过文档 relationships 定位脚注 Part
2. 修改 `<w:footnotePr>` 设置编号和重启规则
3. 遍历每个脚注的段落和 run，设置字体、字号、行距

### 脚注属性设置

- `numFmt=decimal` → 数字编号 (1, 2, 3...)
- `numStart=1` → 从 1 开始
- `numRestart=0` → 每页重新编号

## 5. 字体名称对照

| 中文名 | Word 字体名 | python-docx 中使用 |
|--------|-------------|-------------------|
| 黑体 | SimHei | `FONT_HEI = '黑体'` |
| 宋体 | SimSun | `FONT_SONG = '宋体'` |
| 楷体 | KaiTi | `FONT_KAI = '楷体'` |
| Times New Roman | Times New Roman | `FONT_TNR = 'Times New Roman'` |

## 6. 技术限制

1. **仅支持 .docx**: .doc 格式需要先转换
2. **脚注是已有的**: 不创建新脚注，只格式化现成的
3. **不处理表格和图片**: 只处理文档段落
4. **标题检测依赖内容模式**: 如果论文使用非标准编号 (如 "Chapter 1"), 需要手动调整

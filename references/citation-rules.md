# 自定义注释体例（引注格式）

**默认注释体例依据《法学引注手册》(2019)**。用户未提出自己的要求时，一律按
默认体例修改脚注引注；用户提出自己的注释体例时，优先按用户要求转换。

> 与排版格式的 `--rules`（见 `custom-rules.md`）相互独立：`--rules` 管
> 「字体/字号/行距」等排版，`--citation-rules` 管「脚注引注」的体例。

## 首选用法：对话框里直接说，无需手写 JSON

**用户不需要自己写 `.json` 文件**。用户在对话里用自然语言描述注释体例即可，
skill 会把它翻译成配置并应用。例如：

- 用户说「按法学引注手册规范引注」→ 用默认体例（无需额外配置）
- 用户说「用《法学家》《中外法学》的注释体例（文献引用格式）」→ `--preset 《法学家》《中外法学》注释体例`
- 用户说「用《中国法学》/《法商研究》的引注体例」→ `--preset 《中国法学》` / `--preset 《法商研究》`（两者与法学引注手册一致）
- 用户说「用《法学研究》的注释体例」→ `--preset 《法学研究》`（法学引注手册 + 14 条要求）
- 用户说「版次要放到括号里：《书名》（第N版）」→ 生成 `{"rules": {"edition": true}}`
- 用户说「页码统一用『第N页』，作者和书名之间用冒号」→ 生成对应的
  `conventions` / `rules` 配置
- 用户贴出一段完整注释体例（如「著作类：作者《书名》，出版社年版，第N页；
  论文类：……」）→ 逐条翻译为 `categories` 的 template + 相应 `rules` 开关

翻译规则见下方「三个可配置维度」。翻译完成后把配置写入临时 JSON 文件（或
直接构造体例 dict），经 `--citation-rules` 传入。

## 默认注释体例（《法学引注手册》2019）

- 图书：`作者：《书名》，出版社YYYY年版，第N页。`
- 期刊论文：`作者：《标题》，载《期刊》YYYY年第N期，第N页。`
- 文集文章：`作者：《标题》，载编者主编：《文集》，出版社YYYY年版，第N页。`
- 译著：`[国籍]作者：《书名》，译者译，出版社YYYY年版，第N页。`
- 报纸文章：`作者：《标题》，载《报纸》YYYY年M月D日。`
- 古籍：`（朝代）作者：《书名》，版本，卷N，篇名，第N页。`
- 辞书：`《词典》，出版社YYYY年版，第N页。`
- 网络资料：`作者：《标题》，载网站名，URL，YYYY年M月D日访问。`
- 英文文献：`Author, Title, City: Publisher, Year, p.xx.`
- 其他外文文献：西文体例比照英文，日文体例比照中文。

默认不启用「版次归位」与「译者空格清理」两处自动修复（`edition`/`translator`
默认 `false`）。

## 内置预设

| 预设名 | 说明 |
|---|---|
| `法学引注手册` | 默认体例（不写 `--preset` 即为它） |
| `《法学家》《中外法学》注释体例` | 《法学家》《中外法学》两刊的注释体例（文献引用格式）：著作教材/论文/文集/译著/报纸/古籍/辞书/网络资料/英文/其他外文，启用版次归位与译者空格清理 |
| `《中国法学》` | 与《法学引注手册》(2019) 一致 |
| `《法商研究》` | 与《法学引注手册》(2019) 一致 |
| `《法学研究》` | 在《法学引注手册》(2019) 基础上新增 14 条注释体例要求（见下方） |

### 《法学研究》的 14 条注释体例要求

在《法学引注手册》基础上，《法学研究》新增如下要求（`--show-style --preset 《法学研究》` 会完整列出）：

> **说明**: `notes` (体例要求) 为说明性文本，供人工核对使用，**当前不驱动自动修复**；
> 自动执行范围仅限 `rules` 开关控制的修复规则 (见上方「rules 字段」)。

1. 引用书籍的，要标明作者、书名、出版单位、出版年份和页码。作者为两人的，均列明姓名；为三人及以上的，标注为“××（排名首位的作者）等”。作者为机构的，标注机构名。出版单位属两家（含）及以上机构的，分别列明。
2. 书籍属多人合作作品的，可视情况标注为“××主编”、“××编”。多人分章节合作撰写的编著作品，应在注释中页码后括注“××撰写”。
3. 引用译著的，应在作者前括注作者国籍，书名后增加译者。标注顺序为：国籍、作者、书名、译者、出版单位、出版年份和页码。译著本身未标明原著作者国籍，或者未翻译原著作者姓名的，遵照译著。译者为三人或三人以上的，标注为“××等译”。
4. 引用期刊论文的，要标明作者、文章标题、期刊名及期号、页码。作者为两人的，均列明姓名；为三人及以上的，标注为“××（排名首位的作者）等”。作者为机构的，标注机构名；为课题组的，标注为“××课题组”。
5. 引用文集类书刊（含集刊）中论文的，还要按第 1 条的要求列明该书刊的相关要素。标注顺序为：论文作者、文章标题、书刊作者、书刊名、出版单位、出版年份和页码。其中，论文与书刊之间用“载于”连接。
6. 论文为译文的，应在论文作者前括注作者国籍，文章标题后增加译者。作者国籍不明、作者名原本未译，参照第 3 条酌情处理。
7. 书籍再版或多次修订的，通常应以最新版次为准，但不要标注“第×版”、“修订版”等。论文被转载、摘录的，应引用最早发表的载体。
8. 对报纸的引用，一般限于信息类、数据类引用。引用报纸上的资料，应同时注重报纸及所引内容的权威性、严肃性和专业性。引用报纸文章，要注明作者、文章标题、报纸名、日期和版面序号。作者确实不明的，可免于标注。
9. 对网络资料的引用，一般限于信息类、数据类引用，对由专业机构正式发布的电子期刊或类似网络出版物的引用，不受此限。引用网络资料，要同时注重网站及所引内容的权威性、严肃性和专业性。引用网络资料，要注明作者、文章标题、网址和最新访问日期。
10. 确需引用未公开发表的作品时，需标注作者、作品名称和页码，并视情况标明“××学校博士论文（××年）”、“××机构工作论文”或“××年印行”。
11. 书名或文章标题为若干词语之并列，且词语之间以空格相间，应视情况在相应空格位置添加顿号、逗号或者中圆点。
12. 非直接引用原文的，注释前加“参见”。非引自原始出处的，注释前加“转引自”。已公开的资料，应引用原始文献，禁用转引。
13. 数个注释引自同一出处的，注释采用“前引〔×〕，××书，第×页”或者“前引〔×〕，××文，第×页”。两个注释相邻的，采用“同上书，第×页”或者“同上文，第×页”。相邻两个注释完全相同的，采用“同上”。
14. 引文出自同一资料相邻页者，只注明首页；相邻数页者，注明“第×页以下”。

## 用法

```bash
# 查看默认注释体例（法学引注手册）
python scripts/citation_formatter.py --show-style

# 查看《法学家》《中外法学》注释体例
python scripts/citation_formatter.py --show-style --preset 《法学家》《中外法学》注释体例

# 查看《法学研究》注释体例（含 14 条要求）
python scripts/citation_formatter.py --show-style --preset 《法学研究》

# 仅检查引注（默认体例）
python scripts/citation_formatter.py 论文.docx --check

# 按默认体例修复
python scripts/citation_formatter.py 论文.docx --fix -o 输出.docx

# 按《法学家》《中外法学》注释体例修复
python scripts/citation_formatter.py 论文.docx --fix --preset 《法学家》《中外法学》注释体例 -o 输出.docx

# 按《法学研究》注释体例修复
python scripts/citation_formatter.py 论文.docx --fix --preset 《法学研究》 -o 输出.docx

# 按自定义体例修复（JSON 由 skill 根据用户文字自动生成）
python scripts/citation_formatter.py 论文.docx --fix --citation-rules 我的体例.json

# 主脚本排版 + 引注修复，指定体例/预设
python scripts/format_paper.py 论文.docx --fix-citations --citation-rules 我的体例.json -o 输出.docx
python scripts/format_paper.py 论文.docx --fix-citations --preset 《法学研究》 -o 输出.docx

# markdown 中转工作流 + 自定义体例
python scripts/run_pipeline.py --input 论文.docx --via-markdown --fix-citations --citation-rules 我的体例.json
```

## 配置文件格式

JSON 文件，**只写要改的部分**（未写出的用默认/预设），`_` 开头的键视为注释。三个可配置维度：

| 键 | 含义 | 类型 |
|---|---|---|
| `name` / `description` | 体例名称 / 说明 | 字符串 |
| `rules` | 各修复规则开关 | `{规则名: true/false}` |
| `conventions` | 命名约定 | `{约定名: 值}` |
| `categories` | 各类文献体例的模板 / 示例 | `{类别: {...}}` |
| `notes` | 体例要求/注意事项（字符串列表，如《法学研究》的 14 条） | 字符串列表 |

### rules（修复规则开关）

| 规则名 | 作用 | 默认 |
|---|---|---|
| `punctuation` | 中文标点规范化（，。；：等） | true |
| `author_separator` | 作者名后逗号 → 冒号（作者：《书名》） | true |
| `zai_marker` | 期刊 / 报纸文章补“载” | true |
| `publisher_year` | 出版社补“年版” | true |
| `page_format` | 英文页码 p.xx → 第xx页 | true |
| `edition` | 版次归入括号：《书名》第N版 → 《书名》（第N版） | false |
| `translator` | 译者名与“译”之间多余空格清理 | false |
| `legal_bracket` | 文号方括号 → 六角括号（国发〔2007〕19号） | true |
| `case_bracket` | 案号方括号 → 圆括号（（1998）…） | true |

### conventions（命名约定）

`author_separator`（作者分隔符，默认 `：`）、`multiple_authors_separator`
（多作者分隔，默认 `、`）、`editor_suffix`（默认 `主编`）、`translator_suffix`
（默认 `译`）、`journal_marker`（默认 `载`）、`publisher_year_suffix`
（默认 `年版`）、`edition_marker`（默认 `（第{n}版）`）、`page_prefix` /
`page_suffix`（默认 `第` / `页`）、`page_range_separator`（默认 `-`）、
`english_journal_abbrev`（英文期刊是否缩写，默认 false = 不缩写）。

### categories（各类文献体例模板 / 示例）

每类可改 `name`（类别名）、`template`（格式模板）、`examples`（示例列表）、
`note`（补充说明）。这部分主要用于**展示与人工核对**，不直接参与自动修复；
自动修复行为由 `rules` 与 `conventions` 决定。

## 示例配置

见 `assets/citation_rules.example.json`。例如用户要求「版次放括号里」：

```json
{
  "_说明": "版次归入括号",
  "rules": {"edition": true}
}
```

## 校验规则（加载时报错并给出提示）

- 未知顶层键 / 未知规则名 / 未知约定名 / 未知类别 → 报错
- `rules` 值非 true/false → 报错
- `conventions` 值类型不符（`english_journal_abbrev` 须为布尔）→ 报错
- `examples` 非字符串列表 → 报错
- 配置文件 JSON 解析失败 → 报错

配置出错时脚本输出友好错误并退出（不修改文档），可先用
`python scripts/citation_rules.py 配置.json` 单独校验并预览合并后的体例。
